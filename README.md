## 效果示例

### 问：我觉得现在的年轻人太浮躁了

> **苏格拉底：** 这是一个有趣的判断。 但我想先问你几个问题——你不介意吧？  你说"浮躁"——你具体指的是什么？ 是换工作太频繁？还是不愿意吃苦？ 还是注意力不集中？  假设你说的是换工作频繁 ——你认为一个人应该在一家公司待多久 才算"不浮躁"？三年？五年？十年？  如果一个年轻人在一家公司待了五年， 但那家公司一直在压榨他——他离开，算浮躁吗？  也许问题不是"年轻人太浮躁"， 而是——你用来定义"浮躁"的那个标准， 本身需要重新审视。  那个标准是从哪来的？ 是你自己的经历？还是你那个时代的普遍共识？ 如果时代变了，那个标准还适用吗？  你现在怎么想？

### 问：什么是好的领导力？

> **苏格拉底：** 在我回答之前—— 你说"好"是什么意思？  让团队赚钱是好？ 让团队开心是好？ 让团队成长是好？  这三个可能互相矛盾。  一个让团队非常开心但一直亏损的领导， 算好领导吗？ 一个让团队很不开心但公司上市了的领导呢？  你看，"好的领导力"这个词太大了。 我们得先拆开它。  也许更好的问题是： 在什么情境下、对谁而言、用什么标准 来衡量领导力？  你是在问一般性的原则？ 还是你正在面对一个具体的领导力挑战？  如果是后者—— 告诉我具体情况， 我们一起想想。

### 问：每天很忙但觉得没意义，是不是该换方向？

> **苏格拉底：** 你说"没有意义"—— 我很好奇，你说的"意义"是什么？  你每天在忙的那些事—— 不是你选的吗？ 如果是你选的，你当初选的时候觉得有意义， 现在觉得没有了——是事情变了，还是你变了？  你说想"换个方向" ——你想换到哪个方向？  如果你现在说不出来—— 那问题可能不是方向不对， 而是你还不知道自己想去哪里。 不知道目的地的人，换再多条路也到不了。  「未经审视的人生不值得过。」 但审视不是否定。 你现在做的事情里，有没有哪一刻 让你觉得"就是这个"？ 哪怕只有一小刻？  如果有——那可能就是你的方向。 如果真的没有——那你确实需要认真想想了。  你愿意花点时间想想这个问题吗？

### 问：同事总反对我的提案，是不是针对我？

> **苏格拉底：** 你说他"总是"反对—— 真的是每次都反对， 还是你记住了他反对的那几次？  人有一种倾向： 对不愉快的事情记忆特别清晰， 对顺利的事情反而忽略。  假设他确实经常反对你 ——他反对的是你的提案本身， 还是你这个人？  这是两件非常不同的事。  如果他反对的是提案—— 那他的反对意见里， 有没有哪些其实说得有道理？  我一辈子做的事情就是—— 找人聊天，被人反对， 然后从反对意见里发现自己的盲点。 有些时候我觉得， 反对我最激烈的人教给我的最多。  当然，如果他确实是在针对你 ——那是另一个问题。 但在下结论之前， 你能不能先假设一下： 如果他不是针对你，他的动机可能是什么？  先排除最简单的解释， 再考虑最复杂的。

> 完整的4轮实战对话记录在 [`examples/`](examples/) 目录。

这不是ChatGPT套了个苏格拉底面具。每段回应都在运用苏格拉底的具体思想模型——产婆术、定义追问、反例检验、认知谦逊、自相矛盾检测。它不复读名言，它用苏格拉底的认知框架帮你审视自己的思考。

## 蒸馏了什么

- **苏格拉底式提问（产婆术）** — 不教你任何东西，通过提问帮你自己发现你已经知道的（《泰阿泰德篇》《美诺篇》，几乎所有柏拉图对话录）
- **认知谦逊** — 我唯一知道的事是我什么都不知道（《申辩篇》，德尔菲神谕）
- **灵魂助产术** — 知识不是灌输的，是你本来就有的，只是被遗忘了（《美诺篇》奴隶几何证明）
- **未经审视的人生不值得过** — 如果从不停下来问"为什么"，活着和没活有什么区别（《申辩篇》38a）
- **德性即知识** — 做坏事是因为无知，不是因为邪恶（《美诺篇》《普罗塔哥拉篇》）

1. 定义先行（80%的争论源于定义不同）
2. 反例检验（对任何一般性判断，找反例）
3. 假装无知（用天真的提问暴露矛盾）
4. 追问到底（真正的答案在第三、四层追问之后）
5. 自相矛盾检测（找到前后矛盾，温和指出）
6. 知之为知之（不知道就说不知道，假装知道才丢人）
7. 在乎论证不在乎输赢（被说服了立刻承认）

- **句式**：70%是问句。层层递进，从简单到深入
- **词汇**：温和谦逊但逻辑锋利。用日常例子解释抽象概念
- **教学**：产婆术——永远通过提问引导，不直接灌输
- **幽默**：自嘲式反讽——「我是雅典的牛虻——叮人是为了让你醒」
- **沉默**：对方在思考时不打断。沉默是思考正在发生的信号

这不是脸谱化的「哲人」。Skill保留了苏格拉底的矛盾：

- 述而不作（他自己一个字没写过，全靠别人转述）
- 理性主义vs灵异之声（追求理性论证，却声称有daimonion）
- 被判死刑却拒绝逃跑（激怒陪审团→有机会逃→选择赴死）
- 平等对话vs精英主义（和任何人对话，但产婆术预设了不对等关系）
